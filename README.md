# CHI-unmet-needs
Identify Information Unmet Needs
This code finds Unmet Needs of consumer health information through inter-sentence similarity analysis using three embedding models, LLM assisted topical modeling, and LLM assisted content analysis. Code is a pipeline that discovers the needs of ADHD information. All codes cannot be used without the consent of the author. If you wish to use the code, please contact cjaeeun77@snu.ac.kr .
